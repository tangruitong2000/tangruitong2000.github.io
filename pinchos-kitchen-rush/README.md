# Pinchos Kitchen Rush · Falun

An independent browser game by Ruitong Tang for practising the Pinchos menu in Falun. It includes 41 dishes, simulated orders, and Swedish and English controls. Scores and settings are stored in the player’s browser.

## Play

[Open the game](https://tangruitong2000.github.io/pinchos-kitchen-rush/). To run it locally, open `index.html` with the `assets` folder beside it.

The game uses menu references. Confirm the current menu and kitchen procedures with your trainer.
